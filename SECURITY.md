# Security and privacy

SlipShot handles potentially sensitive pixels locally. Only the current preview branch receives fixes; no stable supported release is claimed yet. See README and TESTING.md for capture, redaction, clipboard and native verification limits.

Please use this repository's **Security → Report a vulnerability** form for a suspected security/privacy issue. Include the affected version, reproduction steps with synthetic data, impact and a proposed fix if available. Do not include personal screenshots, clipboard contents, tokens or user documents. Do not put an unpatched vulnerability or private image in a public issue.

If private reporting is unavailable, open an issue requesting a private reporting channel without disclosing vulnerability details. Response times are not guaranteed for this volunteer project.

Regular bug reports can use GitHub Issues with invented sample content. The installed app does not upload diagnostics, screenshots or crash reports. Temporary drag-out images and Windows clipboard/history have the retention limits documented in README; the app does not promise forensic erasure.
