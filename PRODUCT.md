# LeftShot

Provisional name; no trademark availability claim. Independent, local-only Windows screenshot utility for people who want fast capture and annotation without interrupting their work or games.

Primary path: explicit region capture → bottom-left nonactivating preview → deliberate editor interaction → flattened copy or save. No automatic screenshot saving, network features, telemetry, startup registration or updater. Core precedes optional features. Windows 10 2004+ / Windows 11, x64, WPF .NET 8. Capture is SDR, cursor excluded, one monitor per selection. Cross-monitor regions are explicitly disallowed. Exclusive fullscreen and protected content are not guaranteed.

All development output/cache/temp stays in this repository on F:. Desktop interaction is prohibited during unattended development. No screenshots of the user's desktop, clipboard use, hotkey registration or app launch during verification.
